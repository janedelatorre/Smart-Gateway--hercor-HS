# Smart Gateway V19 — Analytics, Settings & Responsive UI

- Added role-safe Analytics page with date-range KPIs and four compact charts.
- Added Analytics to Administrator and Staff navigation.
- Unified Administrator/Staff dashboard topbars with the shared navbar so profile photos stay synchronized.
- Added Staff Settings with limited account/theme preferences; system/security/kiosk/SMS provider settings remain Administrator-only.
- Added Sent By filter/source classification for SMS Notifications: Kiosk, Administrator, Staff.
- Reports date controls now use From Date / End Date labels, removed the duplicate left calendar icon, and keep the native picker indicator visible/white in dark mode.
- Improved header and hamburger-menu responsiveness and close behavior.
- Added responsive login sizing for short/tall/narrow viewports.
